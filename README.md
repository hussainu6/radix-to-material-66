# Material 3 Theme Editor

Visual Material 3 theme editor. Pick colours with colour pickers and preview on Material-style components. Export a Material 3 JSON theme.

## Run locally

```bash
cd radix-to-material-66
npm i
npm run dev
```

## Features

- **Colour pickers** for all M3 roles (primary, secondary, tertiary, surface, error, etc.)
- **Live preview** with filled/outlined/tonal buttons, chips, cards, text field
- **Export** Material 3 theme as JSON (copy or download)

## Tech

- Vite, React, Tailwind CSS
