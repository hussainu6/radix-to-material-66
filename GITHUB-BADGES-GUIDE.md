# GitHub Badges (Shields) & Achievements Guide

GitHub Badges are specially designed icons displayed on a profile or repository README to signify certain achievements or display information in a clear, concise, and visually appealing manner. They help visualise and share the status, progress, and features of a project.

Badges can show version numbers, build status, test coverage, documentation, issue resolution %, and more.

---

## How to add achievements to your GitHub profile

### Quickdraw

**You will learn:** Create and close issues on GitHub.

**Steps:**

1. Click **Create new issue** (in any repo, e.g. this one).
2. Click **Submit new issue**.
3. Wait 10 seconds.
4. Click **Close issue**.

**Congratulations – you just got the Quickdraw achievement.**

---

### Pull Shark

**You will learn:** Create a public repo, open a PR, and merge it.

**Steps:**

1. Create a new **PUBLIC** repository with README: https://github.com/new
2. Edit **README.md** (add a line or fix a typo).
3. Save README and choose **Create a new branch** for this commit.
4. Click **Create pull request**.
5. Click **Merge pull request**.
6. **Repeat steps 2–5 once more** (you need 2 merged PRs for the achievement).

**Congratulations – you just got the Pull Shark achievement.**

---

### YOLO

**You will learn:** Merge a pull request without code review.

**Steps:**

1. Create a new **PUBLIC** repository with README: https://github.com/new
2. Edit **README.md** (small change: add a line, fix typo, etc.).
3. Save README and **create a new branch** (same flow as Pull Shark).
4. Click **Create pull request**.
5. **Important:** Do **not** request a review. Click **Merge pull request** directly, without any review approvals.

**Congratulations – you just got the YOLO achievement.**

---

### Starstruck

**You will learn:** Get stars on your repository.

**Steps:**

- Have a useful repository (project, notes, awesome lists, etc.).
- Share it where it can help people (socials, forums, README “give a ⭐ if you liked it”).
- When the repo reaches **16 stars**, you get Starstruck.

**Congratulations – you just got the Starstruck achievement.**

---

### Public Sponsor

**You will learn:** Sponsor other users on GitHub.

**Steps:**

1. Add a payment method (e.g. card) on GitHub: https://github.com/sponsors
2. Find a public project that helped you and sponsor its creator.

**Congratulations – you just got the Public Sponsor achievement.**

---

### Galaxy Brain

**You will learn:** Use GitHub Discussions and get accepted answers.

**Note:** The Galaxy Brain badge is no longer awarded in Community Discussions, but you can still earn it in other Discussions (e.g. repo Discussions).

**Steps:**

1. Find a repository with **Discussions** enabled (look for the “Discussions” tab).
2. Find an unanswered question and answer it correctly.
3. Your answer must be marked as **Accepted answer** by the question owner.
4. Get **2 accepted answers** in any category.

**Congratulations – you just got the Galaxy Brain achievement.**

## Can achievements help my profile?

Yes. Achievements do more than look good; they show credibility and engagement.

- **Proof of involvement** – Viewers can see how active you are on GitHub.
- **Areas of expertise** – Achievements hint at what you do (e.g. open source, collaboration).
- **Personal branding** – They make your profile stand out to employers and collaborators.

In short, GitHub achievements can help your profile by highlighting your expertise, commitment, and adaptability.

## How to change emoji skin tone on GitHub

1. Click your **profile photo** (top-right).
2. Click **Settings**.
3. In the left sidebar, click **Appearance**.
4. Scroll to **Emoji skin tone preference**.
5. Select your preferred skin tone – it will apply to supported emojis across the site.
